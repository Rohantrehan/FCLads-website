# FCLads-website

FC Lads is an EA SPORTS FC Ultimate Team community and education platform. Free guides, collections, meta players and squads, plus the FC Lads+ membership.

- `web/`: the Next.js site (`cd web && npm install && npm run dev`)
- `all_pages_design/`: the Google Stitch design exports
- `FC_LADS_PROJECT_REPORT.md`: research, stack and roadmap
- `PROGRESS.md`: what's built, decisions and what's next
